# SadarBudget Android v2.0.29

## Perubahan tema
- Mengganti identitas warna hijau menjadi biru pada tema terang dan gelap.
- Tema terang sekarang memakai kombinasi putih, biru royal, dan biru muda.
- Tema gelap sekarang memakai kombinasi hitam/near-black, biru terang, dan cyan lembut.
- Surface, outline, chip, tombol, navigation selection, chart, indikator pemasukan, dan komponen aksen lain diselaraskan ke keluarga biru.
- Warna merah untuk pengeluaran/error dan amber untuk warning tetap dipertahankan agar makna fungsional jelas.
- Warna laporan PDF/Excel juga diselaraskan ke palet biru agar konsisten dengan aplikasi.
