# SadarBudget Android v2.0.21 — Modern Green UI Refresh

Perubahan utama pada versi ini:

- Merombak palet warna aplikasi menjadi tema putih-hijau untuk mode terang dan hitam-hijau untuk mode gelap.
- Menambahkan dasar layout responsif dengan 4 bucket ukuran layar:
  - mini
  - sedang
  - besar
  - expanded / tablet-landscape
- Merombak homepage / welcome screen dengan gaya yang lebih modern:
  - hero layout baru
  - panel showcase
  - kartu benefit yang lebih rapi
  - pilihan tema terang / gelap yang tetap tersedia
- Memperbarui tampilan dashboard agar lebih modern:
  - hero summary card
  - metric cards baru
  - kartu insight dan tren yang lebih selaras
- Memodernisasi nuansa visual komponen umum:
  - radius kartu lebih konsisten
  - elevasi dan border lebih halus
  - aksen hijau lebih kuat namun tetap bersih
- Memperbarui chart line dan bar agar terlihat lebih modern:
  - tinggi lebih proporsional
  - line chart memakai area fill
  - bar chart memakai sudut membulat
- Menyegarkan top bar, navigation rail, dan bottom bar agar lebih sesuai dengan tampilan baru.

Catatan:
- Fokus revisi ini adalah refresh visual dan fondasi layout responsif.
- Struktur data, mekanisme offline, dan fitur utama tetap dipertahankan.
