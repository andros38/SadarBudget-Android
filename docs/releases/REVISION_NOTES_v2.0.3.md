# SadarBudget Android Offline v2.0.3

- Batas versi pemulihan lokal dikurangi dari 8 menjadi 5 per akun.
- Versi lama otomatis dihapus sehingga hanya 5 snapshot terbaru yang disimpan.
- Foto profil pengguna menggantikan ikon profil di kanan atas bila tersedia.
- Avatar top bar dan halaman Profil ditampilkan bulat.
- Dialog crop foto memakai area panduan lingkaran; file sumber tetap disimpan 512×512 agar kualitas tetap baik.
- Tanpa foto profil, ikon AccountCircle lama tetap digunakan.
