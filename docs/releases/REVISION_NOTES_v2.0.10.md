SadarBudget Android Offline v2.0.10

Optimasi UI responsif lanjutan:
- Landscape/layar lebar memakai navigation rail di sisi kiri sehingga bottom navigation tidak memakan tinggi layar.
- Top bar landscape dipendekkan.
- Menu akun dan menu catat pada landscape memakai dialog kompak.
- Dashboard landscape memakai 3 kartu metrik sejajar dan dua panel analitik berdampingan.
- Filter riwayat transaksi diringkas menjadi satu baris pada landscape.
- Laporan tahunan memakai susunan grid pada landscape.
- Bottom navigation portrait dipadatkan menjadi 58 dp + safe inset sistem.
- Padding, radius, typography, transaction item, dan grafik dibuat lebih hemat ruang pada layar pendek.
